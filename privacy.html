shikumi-upload

プライバシーポリシー

このページは、個人用ツール「shikumi-upload」（以下「本ツール」）での情報の扱いを説明します。

1. 使う情報

本ツールは、Google アカウントでの許可（OAuth）を通じて、次の目的にだけ YouTube Data API を使います。

  • 運営者のチャンネルに動画をアップロードし、タイトル・説明文・公開日時を設定する
  • 同じ動画を二重に上げないよう、チャンネルにある動画のタイトルを読む

2. 保存と送信

許可の情報（トークン）は、運営者のパソコンの中だけに保存します。 YouTube（Google）以外のサーバーや第三者には、情報を送りません。売ったり、広告に使ったりもしません。

3. 許可の取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも本ツールへの許可を取り消せます。

4. Google の規約

本ツールは YouTube API サービスを使っています。 YouTube 利用規約と Google プライバシー ポリシーも適用されます。 Google API から受け取った情報の扱いは、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

5. 変更

内容を変えるときは、このページを更新します。
